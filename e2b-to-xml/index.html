Conversor E2B → XML interno

Sube un mensaje E2B (HL7 ICH ICSR) y descarga el XML en formato interno (DATA_ENTRY / RAM_Entry / MED_Entry / CON_Entry / ASSES_Entry) listo para importar.

Todo ocurre en tu navegador. El archivo E2B no se sube a ningún servidor ni se envía por internet — la conversión se ejecuta localmente con JavaScript. Puedes cerrar la conexión a internet después de cargar esta página y seguirá funcionando.
